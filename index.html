Counted Pick-and-Release Cell

R&D Engineer

A cobot/industrial robot picks metallic parts from a source bin and releases them into a destination container — engineered for 100% verified transfer-count accuracy rather than precision placement.

More details

Hardware concept: paired through-beam IR/photoelectric sensors at each container opening for directional (in/out) detection, plus a V-shaped physical divider that mechanically guarantees correct routing. Load cells serve as an independent cross-check, with time-gating and debounce logic to reject gripper interference.

Modular Multi-Board Vehicle Telemetry System

Technical Lead · 2025–2026 · Shell Eco-marathon Europe

A 4-board stackable PCB system for real-time telemetry on UMAKİT's Shell Eco-marathon competition vehicle: a wireless/GPS gateway board (ESP32-C3 + u-blox NEO-M9N), an STM32-based main controller, a sensor interface board, and a dedicated power management board, connected via a compact standoff stack architecture.

More details

Acquires real-time telemetry — GPS position, motor performance, battery status — and transmits it over MQTT/TLS to a live web dashboard for race strategy monitoring. Fully assembled, tested, and deployed on the competition vehicle.

BLDC Motor Driver Firmware

Technical Lead · UMAKİT, 2025–2026

Firmware for a brushless DC motor driver controlling a Mitsuba M1048R motor on an STM32 microcontroller. Implemented Hall-sensor-based commutation for rotor position sensing, dead-time tuning in the gate driver stage to prevent shoot-through, and smooth throttle ramping for controlled acceleration.

More details

Measured and tuned dead-time to ~120 ns via oscilloscope characterization at a ~7.8 kHz switching frequency, eliminating shoot-through across the full switching cycle.
